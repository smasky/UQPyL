# Optimization 架构约定：Population

## 结论

`Population` 保留为单一类，不拆成两个大类。  
但必须显式承认它存在两种合法状态：

| 状态 | 含义 |
|---|---|
| 未评估 | 只有 `decs`，还没有 `objs/cons` |
| 已评估 | 拥有 `decs`，且已有 `objs`，可选有 `cons` |

主原则：

1. `Population` 是候选解批量容器。
2. `Population` 不再负责 `Problem` 评估协议。
3. `Population` 不再承担变量空间变换。
4. 所有依赖目标值/约束值的操作都必须先检查评估状态。

---

## 一句话定义

> `Population` 表示一批候选解；它始终拥有 `decs`，可选拥有 `objs/cons`；所有依赖评估结果的操作都要求它处于已评估状态。

---

## 职责边界

### `Population` 应该负责什么

| 职责 | 说明 |
|---|---|
| 数据承载 | 保存 `decs`、`objs`、`cons` |
| 容器行为 | 切片、复制、长度、大小 |
| 群体操作 | 合并、替换、裁剪 |
| 排序选择 | `argsort()`、`getBest()`、`getParetoFront()` |
| 排序缓存 | `frontNo`、`crowdDis` |

### `Population` 不应该负责什么

| 职责 | 处理 |
|---|---|
| `problem.evaluate()` 调度 | 移出 |
| `_transform_*` 变量变换 | 移出 |
| `problem.opt` 符号翻转 | 移出 |
| 显示态/真值态转换 | 移出 |
| 导出、日志、GUI | 移出 |

---

## 合法数据形态

`Population` 允许以下两种正式形态：

| 构造形态 | 含义 |
|---|---|
| `Population(decs=...)` | 待评估候选集 |
| `Population(decs=..., objs=..., cons=...)` | 已评估候选集 |

说明：

| 项 | 结论 |
|---|---|
| `decs` | 必须存在 |
| `objs` | 可选 |
| `cons` | 可选 |
| “未评估” 是否是正式状态 | 是 |

---

## 状态语义

方案采用显式状态约束。

建议接口：

| 接口 | 用途 |
|---|---|
| `isEvaluated` | 判断是否已评估 |
| `hasCons` | 判断是否存在约束值 |
| `requireEvaluated()` | 依赖评估结果的方法先调用 |
| `requireConsistentEvalState(other)` | 合并或替换前检查状态一致性 |

结论：

1. 允许 `objs is None`。
2. 但不允许“假装已评估”。
3. 所有依赖 `objs/cons` 的接口必须显式断言。

---

## 方法分层

### 不要求已评估的方法

| 方法 | 说明 |
|---|---|
| `copy()` | 复制容器 |
| `clip()` | 决策变量裁剪 |
| `__getitem__()` | 切片 |
| `__len__()` | 长度 |
| `size()` | 规模 |
| `merge()` | 允许，但要求双方状态一致 |
| `merged()` | 允许，但要求双方状态一致 |
| `replace()` | 允许，但要求双方状态一致 |

### 要求已评估的方法

| 方法 | 说明 |
|---|---|
| `argsort()` | 依赖 `objs`，可选依赖 `cons` |
| `getBest()` | 依赖排序结果 |
| `getParetoFront()` | 多目标依赖 `objs` |

---

## 合并规则

`merge()` 采用原地语义，`merged()` 返回新对象。

### 1. `merge(other)`

定义：  
把 `other` 合并到当前 `Population`，原地修改自身。

### 2. `merged(other)`

定义：  
返回新的合并结果，不修改自身。

### 合并合法性规则

| 左侧 | 右侧 | 是否允许 | 结果 |
|---|---|---|---|
| 未评估 | 未评估 | 允许 | 合并 `decs`，结果仍未评估 |
| 已评估 | 已评估 | 允许 | 合并 `decs/objs/cons` |
| 未评估 | 已评估 | 不允许 | 直接报错 |
| 已评估 | 未评估 | 不允许 | 直接报错 |

附加规则：

| 情况 | 处理 |
|---|---|
| 两边都已评估，但一边有 `cons` 一边没有 `cons` | 报错 |
| `conWgt` 语义不一致 | 报错 |

结论：  
不做兜底，不做自动补齐，不做启发式合并。

---

## 替换规则

`replace(index, other)` 采用原地语义。

定义：  
将 `other` 替换到当前 `Population` 指定位置。

合法性规则：

| 当前状态 | `other` 状态 | 是否允许 |
|---|---|---|
| 未评估 | 未评估 | 允许 |
| 已评估 | 已评估 | 允许 |
| 已评估 | 未评估 | 不允许 |
| 未评估 | 已评估 | 不允许 |

结论：  
`replace()` 只做结构替换，不做智能补全。

---

## 推荐保留的方法

| 方法 | 是否保留 | 说明 |
|---|---|---|
| `copy()` | 保留 | 基础容器能力 |
| `merge()` | 保留 | 原地合并主入口 |
| `merged()` | 新增 | 返回新对象版本 |
| `replace()` | 保留 | 原地替换 |
| `getBest()` | 保留 | 统一选优入口 |
| `getParetoFront()` | 可保留 | 多目标常用接口 |
| `argsort()` | 保留 | 排序基础能力 |
| `clip()` | 保留 | 纯数据修正 |
| `__getitem__()` | 保留 | 切片 |
| `__len__()` | 保留 | 容器语义 |
| `size()` | 保留 | 规模语义 |

---

## 推荐删除的旧职责

| 旧接口/旧职责 | 处理 |
|---|---|
| `evaluate(problem)` | 删除 |
| 内部调用 `problem.evaluate()` | 删除 |
| `_transform_discrete_var()` 相关逻辑 | 删除 |
| `_transform_int_var()` 相关逻辑 | 删除 |
| `problem.opt` 符号处理 | 删除 |
| “真实空间/显示空间”转换 | 删除 |

---

## 与其他核心对象的依赖关系

| 对象 | 与 `Population` 的关系 |
|---|---|
| `Problem` | 不直接耦合 |
| `Algorithm` | 负责生成、评估、写回 `Population` |
| `OptState` | 保存当前 `Population` 与历史快照 |
| `OptResult` | 不直接依赖 `Population` 行为，只消费结果 |

后续正式数据流：

| 步骤 | 负责人 |
|---|---|
| 生成 `decs` | `Algorithm` |
| 输入空间变换 | `Problem` / `Space` |
| 真实评估 | `Problem.evaluate()` |
| 结果写回 `Population` | `Algorithm` |
| 排序与选优 | `Population` |

---

## 方法命名结论

| 方法 | 语义 | 结论 |
|---|---|---|
| `merge()` | 原地合并 | 主入口 |
| `merged()` | 返回新对象 | 推荐新增 |
| `replace()` | 原地替换 | 保留 |

说明：  
默认操作风格采用原地语义，同时保留显式返回新对象的变体，避免接口含糊。

---

## 一句话总纲

`Population` 只处理“候选解怎么存、怎么拼、怎么排、怎么选”，  
不再处理“怎么评估、怎么变换、怎么展示”。
