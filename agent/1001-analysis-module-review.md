## SA01：Morris 差分的数据类型

位置：`UQPyL/analysis/methods/morris.py` 第 123–124 行，直接对原始 X/Y 使用 `np.diff`；公共形状检查未把它们统一转换成浮点计算数组。

一输入范围 [0,1]，8 条合法 Morris 轨迹，采样 seed=17，`Y=1[X>0.5]`。每条轨迹都跨过阈值，标准有符号单位步长为 ±2/3，故每个基本效应均为 1.5；独立参照为 mu=mu_star=1.5、sigma=0。

| 相同数值采用的输出类型 | mu | mu_star | sigma |
|---|---:|---:|---:|
| float64 | 1.5 | 1.5 | 0 |
| uint8 | -190.5 | 192 | 205.256634 |
| bool（外部提供 Y） | 0 | 1.5 | 1.603567 |

uint8 的下降差分 `0-1` 回绕为 255；布尔差分只保留“发生变化”，丢失方向。这与 [NumPy 官方 diff 文档](https://numpy.org/doc/stable/reference/generated/numpy.diff.html) 描述的数据类型行为一致。异常结果全部为有限数，因此现有 EE 有限性检查不会发现。

**真实模型回调返回 uint8 时同样复现**，不是仅限手工传入 Y。另一个合法整数输入案例，范围 [0,2]、`Y=X`，标准效应应为 2：浮点 X 得到 2，外部 uint8 X 得到 mu≈0.993114、mu_star≈1.006886。应对 X 和 Y 都使用计算副本，不能只修输出侧。这与前轮删除 physical 模式无关，单位区间公式在浮点对照中正确。

## SA02：RBDFAST 的固定列与重复取值

位置：`UQPyL/analysis/methods/rbd_fast.py` 第 96–98 行：按参数排序后构造偶数/反向奇数序列，没有固定列或并列值处理。

256 行样本中 x0 恒为 0，x1 等间距覆盖 [0,1]，`Y=x1`。x0 没有变化也不影响输出，其贡献应为零。当前有序样本得到 **S1=[0.997629,0.997629]**；对同一 X/Y 成对重排后，x0 分数依次变为 0（seed=0、17）或 0.036058（seed=41），x1 基本不变。

非恒定重复取值也有类似问题：x0 为整数 0/1，两组各 128 行、x1 和 Y 的分布完全相同，组成独立的笛卡尔积，理论指标 [0,1]。有序样本 x0 得分 **0.721277**，重排后变为 0。并列排序留下的行顺序会被频谱分析误认为效应。

这不能外推为“RBDFAST 的连续随机样本公式整体错误”。本轮 1024 行连续 LHS 对照得到 **[0,0.997681]**。建议固定列明确返回零/不可评估诊断；重复值与离散变量需明确支持策略或适用性限制，仅换成稳定排序不能消除该问题。

## SA03：RSA 极端输出与非有限数据

位置：`UQPyL/analysis/methods/rsa.py` 第 69、96、110–117 行：输出未经有限性检查直接求分位数；无有效区域或 NaN 统计量汇总成零。

独立四行参照：`X=[0,1/3,2/3,1]`、`Y=[-1,-1,1,1]`、nRegion=2。区域的输入秩为 [1,2] 和 [3,4]，双样本 Cramér–von Mises 统计量手算为 `1-15/24=0.375`；两个区域的平均仍为 0.375。输出乘正数不应改变秩或区域成员。

| 输出倍率 | 当前 S1 | 独立参照 |
|---|---:|---:|
| 1 | 0.375 | 0.375 |
| 1e-200 | 0.375 | 0.375 |
| 1e308 | **0** | **0.375** |

最后一行原始输出全为有限数 ±1e308，但分位数插值中的减法溢出，出现 `overflow encountered in subtract`，随后错误归零。

把一个输出或输入改为 NaN，也会**没有 warning 地返回零**。±inf 输出未被拒绝，出现 NumPy warning；+inf 案例变零，-inf 案例仍返回 0.375，均没有明确无效数据诊断。建议先检查 X/Y 有限性，采用安全尺度计算输出分区。保留合法恒定输出的零分约定，但不能将无效数据等同于没有敏感性。

## SA04：FAST 采样块被破坏后仍计算

位置：`UQPyL/analysis/methods/fast.py` 第 104、123–125 行：`n=int(行数/nInput)` 截断后重新分块；没有核对行数整除或 metadata 的 N。

两输入、`Y=x1`，FASTDesign(M=4)、N=129、seed=3，metadata 对应 258 行：

| 输入情况 | 行数 | x1 的 S1 | 当前行为 |
|---|---:|---:|---|
| 完整采样设计 | 258 | 0.997707 | 正常参照 |
| 丢失最后一行 | 257 | **0.016004** | 无错误、无 warning |
| 丢失最后两行 | 256 | **0.016004** | 行数可整除，但与 metadata 不一致，仍接受 |
| 多加一行，额外 Y=1e200 | 259 | 0.997707 | 额外行被静默忽略 |

丢行会改变频率和块边界；归一化后的 S1_norm 仍接近 [0,1]，不能依靠归一化分数发现结构破坏。这属于无效设计缺少防护，不是完整设计中的公式错误。[SALib 的 FAST 实现](https://salib.readthedocs.io/en/latest/_modules/SALib/analyze/fast.html) 明确拒绝无法按维数整除的样本；本项目还携带 metadata，应进一步核对块长度及完整行数。

## SA05：RBDFAST 的谐波预算

位置：`UQPyL/analysis/methods/rbd_fast.py` 第 110–115 行：偏差系数 λ=2M/N；λ≈1 时直接跳过修正，λ>1 时使用无效分母再截断。

固定随机样本 seed=17、`Y=x1`，(N,M)=(8,4)、(8,5)、(16,12)，λ 分别为 1、1.25、1.5。**三组均返回 S1=[1,1]，没有 warning。** 应在频谱计算前检查 M 为有效正整数、N 与谐波数量足够匹配，不能把无法估计的配置包装成最大敏感性。

## SA06：Sobol 的实际分母为零

位置：`UQPyL/analysis/methods/sobol.py` 第 115–127、199 行。当前只检查所有样本的输出标准差；第一阶估计分母却来自 A/B 基础样本方差。

真实模型 `Y=1[x0>0.85 且 x1>0.85]`，独立 U[0,1] 输入。合法 SaltelliDesign(secondOrder=False)、N=16、seed=1：A/B 基础样本全部为零，但混合样本出现一次事件，全体输出方差为 0.015381。入口常数检查通过，随后抛出 **ZeroDivisionError: float division by zero**。

这是稀有事件模型的小样本退化，不说明 Sobol 在正常方差样本上的公式错误。独立总体参照 q=0.15，两个参数 S1=q/(1+q)=0.130435、ST=1/(1+q)=0.869565。N=4096、seed=17 的对照得到 S1=[0.122312,0.134179]、ST=[0.878426,0.861747]，与参照近似一致。

建议检查实际 A/B 方差，明确说明样本不足、应增加采样量；不能把这种基础样本未观察到事件的情况当成总体恒定输出而静默归零。

## SA07：Morris 单轨迹标准差

位置：`UQPyL/analysis/methods/morris.py` 第 102、154 行。采样器允许 1 条轨迹，但 sigma 使用 ddof=1。

一条合法轨迹、线性 `Y=X`：mu=mu_star=1，sigma=NaN，同时出现 `Degrees of freedom <= 0 for slice` 和 `invalid value encountered in divide`。样本标准差在只有一个基本效应时确实无法估计，问题是缺少明确的样本充分性处理。

建议要求至少两条轨迹，或给出专门的不足样本诊断并明确 sigma 的可用性；不建议填 0 来制造“没有非线性或交互”的结论。用户要求 MARS 低 R² 使用 warning，不自动等同于其他方法所有无效样本都必须继续返回。
