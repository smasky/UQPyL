# 模块复测范围盘点（2026-10-02）

本轮核对目录、tests/README、实际测试内容及近期审查报告，没有运行新的数值实验或修改生产代码。最新 py312 全量为 2636 passed；不能把“独立数值复测尚不完整”写成“没有测试”。

| 模块 | 已有证据 | 尚缺的系统复测 |
|---|---|---|
| surrogate | 数值/预测精度、噪声范围、收敛诊断专项 | 高维/不连续/外推及通用区间校准仍有限，近期已重点复测 |
| analysis | 解析参照、采样布局、尺度与边界多轮专项 | SA09 极端输入范围、SA11 派生量范围仍待处理；MARS 高阶贡献准确性非普遍保证 |
| calibration | 指标独立参照与尺度修复；集合增益独立伪逆；ES/IES/GLUE/SUFI2 有流程和边界回归 | 整体校准效果：已知参数/线性高斯参照、噪声与相关观测、多种样本量、后验均值/协方差和区间（按各方法语义） |
| inference | 提议尺度修复；多个能量基准、边界/持久化；R-hat/ESS 固定参照 | 长链解析目标的采样分布、均值/协方差、相关目标/混合/多峰与种子稳定性；找到较好能量点不等于后验分布正确 |
| doe | 形状/边界/可复现/映射测试，敏感性设计在 analysis 联动验证 | 全采样器独立几何/统计属性：LHS 每层占用与改进准则、Sobol 序列参照、Saltelli 混合块、Morris 轨迹等，检查已有联动证据后补缺 |
| optimization | 多优化器 smoke/预算/边界/状态回归；HV/GD/IGD/NDSort 独立参照；PSO/GA/NSGAII 部分实际约束运行 | 各算法数值更新和选择规则、可行性、多种子固定预算的性能分布；不能用随机必须到最优点替代算法正确性 |
| problem/core | Eval/离散映射专项；运行态/reader/SQLite/失败等回归，历史端到端验证 | 本次最近修改后的完整跨模块工作流、复杂混合变量和保存读回联动可后置复核 |
| viz | 图形生成、读库、平滑和边界回归 | 面向实际图形的视觉核对，以及图中数据与源结果逐项一致；优先级低于数值模块 |

建议顺序：calibration → inference → doe → optimization → problem/core/viz 跨模块联动。先复核可解析的正确性，再研究统计稳定性，不以增加测试数量为目标。

已知待处理与新复测范围分开：极小尺度校准 RMSE、SA09/SA11 仍未解决；用户暂缓的 C15 一般 R 大规模优化、C17 约束引导选点、C20 精确续跑不自动恢复。最新变更尚未重建 3.14 wheel/完成远程 CI，不能用 py312 2636 项代替其他环境验收。
