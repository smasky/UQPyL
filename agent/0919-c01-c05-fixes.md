# 2026-09-19 C01—C05 修复

范围：按用户要求修复全局审查中的 C01—C05；保留之前 B01—B06 的工作区修改，不发布正式版本。

## 修改与行为

- **C01：坐标串联。** AnalysisABC 在调用方法核心前绑定位置/关键字参数并检查元数据。output="unit" 时解码为真实坐标再评价/分析；已有 Y 视为对应这些样本的输出，不重新评价或缩放。结果保存真实 X，meta.output="real"、source_output="unit"，不改调用者数组和元数据。无 output 保留 real 语义，未知标签报错。位置传入的 meta 现在同样会经过 checkMeta。
- **C02：推断返回隔离。** InfState.buildResult 深复制 history/settings/diagnostics/extra；InfResult.toDict 的嵌套字典也独立。五种推断算法重复运行、reset 和下一次失败均不改变旧结果；嵌套数组视图和列表双向隔离。
- **C03：推断目标方向。** InfResult.objs 在返回边界还原原始目标方向；bestObjs 保持原始方向。SQLite 的样本快照从已导出的 result 写入，与最终 artifact/读回一致。内部 Chain/InfState、接受判断及自定义 logProbFunc 的输入仍使用内部方向，logProb 不变。旧测试中“公开 trace 使用内部方向”的断言已改为逐点核对 Problem.evaluate；这是开发期协议修正，未提供旧数据库迁移。
- **C04：校准边界。** ES/IES 共用初始 ensemble 校验与更新投影。每次有限连续更新按声明的箱型边界投影后才调用模拟器；范围内公式不变。diagnostics["boundUpdates"] 逐次记录 adjusted_members/adjusted_values。初始越界、非有限样本、反向边界或成员不足直接报错；整数/离散变量和一般约束明确拒绝。固定维度保留；没有新增模拟次数。
- **C04 的数值边界。** 采用投影的受边界限制版本，越界更新会改变，可能使部分成员落在边界甚至重合；不宣称投影改善所有任务的后验质量或保持原无约束公式。当前未加入新的约束优化器、噪声或正则项。
- **C05：Morris 量纲。** 按每输出的最大基本效应绝对值缩放后计算均值、绝对均值与标准差，再还原有量纲的 mu/mu_star/sigma；归一化使用缩放后的绝对均值，只将真正零总效应视作零。避免 isclose 的绝对阈值误判及标准差平方在大/小量纲下的溢出/下溢。非有限基本效应明确报错。

中英文 analysis/inference/calibration API 已同步。无新增依赖。
