# 2026-10-02 可恢复的 RBF 奇异系统改为 warning

用户要求“尽量不要报错，以 warning 就行”，并要求不能隐藏计算问题。本轮将 RBF 可恢复的奇异系统从直接报错调整为 **RuntimeWarning + 保留约束的最小二乘近似 + 残差诊断**。方差浮点范围与恒定目标 R² 已采用 warning，继续保持。

## 计算行为

- 正常可逆系统仍执行完整 LU 三角求解，保持 SR01 的单位换算修复。
- 零平滑重复输入、不可辨识的多项式趋势，或三角求解发现奇异时，进入近似求解。
- 多项式约束通过尾矩阵转置的零空间保留。在这个约束空间中拟合训练目标，并对设计列做尺度整理；没有恢复原先分别对 LU 因子取伪逆的错误做法。
- warning 明确告知近似求解、相对训练残差，以及精确插值/唯一外推不受保证；没有删掉冲突观测，也没有静默添加平滑。
- `fitState["linearSolve"]` 保存 `method`；近似路径另有 `rank`、`columns`、`relativeTrainingResidual`、`constraintMaxAbsResidual`、`repeatedInputs` 和 `deficientTrend`。相对训练残差按预处理后的目标计算，不能直接当作原始单位的 RMSE。
- 后续正常重拟合会替换近似诊断；近似求解仍无法收敛或得到非有限系数/预测时，拟合停止并清理旧状态。

例如 `X=[0,0,1]`、`Y=[0,2,1]`：同一输入 0 同时要求输出 0 和 2，无法精确满足。现在告警后给出常数 1 的近似，训练相对残差为 `sqrt(2/5)`，明确记录为 `constrained_lstsq`。这让计算继续，但没有把矛盾数据声明为已精确拟合。

仍保留失败的情况：非法 nu/负噪声参数、NaN/inf 训练数据、错误数组形状、求解失败和非有限结果。它们无法通过 warning 生成有效模型；本轮未裁剪参数、填补 NaN、丢弃数据或返回零来假装成功。
