# 2026-09-30 MARS / DeltaTest 剩余风险实测

用户要求进一步检测并判断是否有必要修正。本轮只增加验证脚本和证据，不改生产算法，不提交/推送。conda py312；MARS 留出 R²<0.8 仅 warning 的用户约定保持。

共 **299 组记录**，包括等距近邻/行排列、输出量级、MARS 样本量/划分/阶数、冗余输入，以及 DeltaTest 样本量/邻居数/噪声/维数。这里的记录数量不是新增 pytest 项数，也不表示所有实验符合正确性要求；其中包含明确反例。

## 结论与修正必要性

| 项目 | 实测结论 | 是否修正 |
|---|---|---|
| DeltaTest 等距近邻 | 同一数据仅改变行顺序，可改变分数甚至第一名；连续无并列对照没有此现象 | 有必要明确并实现与行顺序无关的并列策略 |
| 两方法极小输出 | 输出乘 1e-200，数据仍有限且非恒定，但归一化分数错误地全零 | 有必要把归一化放在输出尺度恢复之前 |
| 极大原始分数 | 输出乘 1e155/1e200 后平方量超出 float64；Delta 抛 ValueError，MARS 泄露 OverflowError | 原始量不可表示是浮点限制；MARS 应统一显式的范围诊断，不能声称能返回准确有限原始值 |
| MARS 高阶交互 | 高验证 R² 仍可漏掉三阶交互；maxDegree=3 在选定对照中改善 | 已有阶数配置；需要针对实际模型对照，不据此自动提高默认值 |
| MARS 单次留出 | 已检查的普通模型都保留正确活跃组；重复划分分数有统计波动 | 可选多次划分有价值，尚无证据要求强制默认开启 |
| Delta 高维/噪声/邻居数 | 本轮 144 组线性筛选实验全部找对两个活跃变量 | 此范围没有发现需要更改估计器的实现错误 |
| 相关冗余输入 | 两个完全重复的变量删任意一个都不损失信息，原始分数全零 | 条件删变量指标的含义，不直接作为算错或人为强制正分 |

## 等距近邻反例

[脚本](verification/check_analysis_remaining.py)、[原始记录](verification/0930-analysis-remaining.json)、[日志](verification/0930-analysis-remaining.txt)。三个样本集（4×4 网格、网格每点重复三次、64 个连续随机点），k=1/2/5，每种十次行排列，共 90 组。

模型 `Y=x0+1.2*x1`，各轴相同范围。近邻的等距并列来自规则网格及删变量后的重复投影。相同 X/Y 作为成对行一起排列，没有改变任何样本内容，也没有重新抽样。

k=1 的网格原始分数范围：x0 约 0.06306～0.15681，x1 约 0.14222～0.30917。重复网格 x0 约 0.14120～0.20718，x1 约 0.16667～0.27500；十次排列中第一名确实在 x0/x1 间变动。连续样本 k=1/2/5 的分数对十次排列保持一致，支持问题来自并列邻居而不是一般浮点求和或样本随机性。

独立的 `tieAveragedDelta` 用全部逐对距离计算第 k 个距离；严格更近的 m 个全部计入，将剩余 k-m 个名额均匀分配给截止距离上的全部 L 个等距点。每行平方误差为：

`[sum(closer squared differences) + (k-m)*mean(tied squared differences)] / k`

最后对行平均并乘 1/2。这是对所有合法等距选择的期望，保持有效 k 个名额，自身按索引排除。它是建议采用的公开并列定义，并非声称原始 Delta 论文规定了此扩展。重复网格 k=1 的独立对照分数约 `[0.151515,0.218182]`。

建议只在第 k 个距离存在额外并列时查询并处理全部候选；无并列路径继续使用 KDTree 快路径。不能只按行索引打破并列，因为重新排列后行索引也变了；直接把所有截止内点等权平均则会改变严格近邻与并列组之间的权重。大量重复点时也要考虑候选数量和峰值内存。

## 输出尺度反例

两种方法×7 种尺度共 14 组。模型 `Y=3*x0+1`，LHS 256 行；尺度为 1、1e-6、1e-160、1e-200、1e100、1e155、1e200。

| 方法 | 正常输出的归一化 | 输出×1e-200 |
|---|---|---|
| DeltaTest | `[0.993618,-0.006382]` | `[0,0]`，并出现“无正分数”提示 |
| MARS | `[1,0]` | `[0,0]`，未出现质量 warning |

原始分数的真实量级约 1e-400，低于 float64 表示范围，原始值下溢本身无法靠有限双精度保留。但是无量纲归一化可以通过缩放后的计算得到；当前先恢复原始平方单位再归一化，使可避免的归一化信息也丢失。因此值得修正，不能把全零归因于输出恒定或变量无影响。

建议以安全的输出中心化/缩放形式计算 Delta 或 GCV 增量、先完成归一化，再尽可能恢复原始量纲；原始量超出范围时单独给出明确诊断。应说明原始下溢为零时，归一化源于缩放前的估计而不是已经舍入为零的数组。不要静默更改原始 S1 的单位，也不要用 np.isclose 再清掉合法小量。

输出×1e155/1e200：Delta 当前明确拒绝非有限分数，MARS 的 `outputScale**2` 在有限值检查之前抛 OverflowError。后者应改为受控范围处理。普通尺度的自适应 MARS 原始量仍有近似拟合差异，本轮单活跃模型输出×1e-6 后原始平方尺度复原差异约 0.87%，归一化仍为 [1,0]，不能继续只引用先前案例的 0.32% 作为普遍上限。

## MARS 稳定性和三阶交互

4 个五维模型×3 个采样种子×2 个样本量（128/512）×2 次数据排列，共 48 组。不同排列使固定局部种子 0 对应不同留出行；不修改生产划分规则。

- 加性：`3*x0+x1²`，活跃维度 [0,1]。
- 二阶：`x0*x1+0.2*x2`，活跃维度 [0,1,2]。
- 三阶：`3*x0+2*x1*x2*x3`，活跃维度 [0,1,2,3]。
- 噪声：`3*x0+2*x1+0.2*epsilon`，epsilon 由独立随机流产生，活跃维度 [0,1]。

普通加性/二阶/小噪声共 36 组，最低验证 R² 分别约 0.999996 / 0.999942 / 0.984200；活跃组均高于无关组。两次划分的单个归一化分数最大绝对变化分别约 0.00297 / 0.06073 / 0.02489。这里是绝对分数差，不能把二阶案例约 6.07 个百分点说成通用误差率；两个交互变量本来具有相同作用，互换第一名也不直接构成错误。

三阶模型 12 组验证 R² 均大于 0.8（最低约 0.87984），所以都没有质量 warning；其中两个案例的真实活跃变量分数低于某个无关变量。seed=41、N=128、第二种划分的 R²≈0.96728，却输出 `[1,0,0,0,0]`。主效应方差为 3，交互方差为 4/27，只拟合主效应也能得到较高 R²；全局预测质量阈值不能证明每个较弱交互被捕获。

另做两组阶数对照：seed=17、N=512，degree=2 时 R²≈0.92638，权重 `[0.997595,0,0,0.002405,0]`；degree=3 时 R²≈0.97843，权重 `[0.904126,0.032378,0.031088,0.032408,0]`，找出了三个交互变量。但 degree=3 对照中，移除无关变量使 GCV 从约 0.0298 降到 0.0000129，说明前向选择路径仍影响拟合质量。未宣称只提高阶数就全面保证可靠。

建议保留现有二阶默认和 0.8/warning 约定，对疑似高阶模型比较 maxDegree=2/3 及不同划分，并利用已有完整/删变量 GCV 诊断。单次留出本轮未成为必须改变默认算法的证据；可选稳定性诊断可另行设计。

## DeltaTest 样本量、邻居数、噪声和维数

[脚本](verification/check_delta_stability.py)、[JSON](verification/0930-delta-stability.json)、[日志](verification/0930-delta-stability.txt)。3/10 维×128/512/2048 行×三个种子×噪声标准差 0/1.5×k=1/2/5/10，共 144 组。

模型 `3*x0+2*x1+noise`，其他维度无关。全部 144 组 x0 第一且前两名恰为 [x0,x1]。这是线性、独立均匀输入下的有限配置结论，不能推广成任意十维非线性、相关或高噪声数据都可靠。

另有一组 X1=X0、Y=X0 的冗余输入，Delta 删任意一个都可用另一个找相同近邻，因此原始分数全零并 warning。此类数据里指标描述的是独有增量，不能强行要求两个变量各占 50%。
