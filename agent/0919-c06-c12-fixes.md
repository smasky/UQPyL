## 修改与行为

- **C06：MOASMO 种群配置。** `nPop` 传给默认 NSGAII；用户提供 optimizer 时保留该实例自己的种群数。
- **C07：MOASMO 实例复用。** 用引用区分自动集合与用户提供的集合，自动代理每次运行重建，支持目标数和输入维度变化；显式替换代理仍生效。自定义 MultiSurrogate 保留集合及子模型引用，在真实评价前检查输出数、模型数、模型类型及重复实例。支持已有 fit/predict 包装器；包装器若提供 n_surrogates，也会提前检查输出数，未提供时不猜测内部模型或增加试评价。
- **C08：MARS 重训。** resetFitState 清理旧 basis、coef、变量标签、训练轨迹、重要性及拟合指标，避免旧列数进入新训练校验。失败后仍要求重新成功拟合；关闭剪枝重新训练不会残留旧剪枝轨迹。数学训练流程及编译源码不变。
- **C09：优化通用配置。** 通用字段以实际运行属性为唯一来源，set/get 与 exportConfig 共用映射，maxIters 对应 maxIter；不再在 Params 中另存通用字段副本。historyFreq 保留已有校验；hvRefPoint 赋值/读取复制数组并在 setter 中清理缓存。日志改用 exportConfig，与保存配置一致。配置约定为运行前调整；普通算法专属参数继续保存在 Params。
- **C10：代理散点图。** 默认坐标按真实值与预测值的联合跨度加 10% 边距；常数用其绝对值与 1 的较大值生成非零边距。负数、跨零、常数均完整可见；显式 ylim 原样优先。
- **C11：结果身份。** OptResult 增加独立的 runId、method、problemName、nInput、nOutput、nCon、createdAt；summary/toDict 输出 snake_case。创建时间在运行 reset 时建立，SQLite 使用同一时间，reader 从 run 表恢复元数据。不依赖保存开关，不受算法复用/reset 影响；手动构造的结果可省略这些可选字段。
- **C12：校准提前校验。** ES/IES 在首次模拟前检查有效观测非空/有限、R 的形状/有限性/对称性/半正定性；IES 检查当前 lam 与非负整数 maxIters。零轮保留只评价初始集合的语义。单步入口同样提前校验；正式循环复用已校验的观测与 R，每轮只计算变化后的集合更新。成员数等入口校验沿用 C04，不改变更新公式或增加模拟调用。

中英文 optimization/surrogate/calibration API 已同步，无新增依赖。
