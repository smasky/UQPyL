### N02 · 2026-09-08

- **根因与修复：** Boxmin 原有乘法探索及位置比值外推直接作用于负数、跨零参数，导致越界或零点停滞。现在将有限参数范围映射到内部 `[1, 2]`，目标评价和返回值恢复到传入坐标；该坐标可能已是超参数的 log 坐标，不改变 Problem 的 unit 约定或代理模型训练输入。每次评价前保护原始边界；固定维度不探索，初始点先复制并裁剪，非法边界与初始点在评价前报错。
- **精度回归已处理：** 初版映射保留原固定 2～4 轮搜索时，既有正弦拟合测试失败；没有放宽原数值标准，改为步长因子全部缩小到距 1 不超过 0.001 时停止，并跳过外推中完全未移动的点。此条件限制搜索分辨率，不承诺全局最优。

### N10 · 2026-09-08

- **根因与修复：** `_lhs_correlate` 原先以 corrcoef 默认行方向计算样本间相关性，并用 `R != 1` 排除对角线，可能连完全正相关的非对角元素一起排除。现在使用 `rowvar=False`，按严格上三角位置取变量对相关系数，统一以最大绝对相关系数选优。移除内部候选打印，候选数组直接保留引用，无多余复制。
- **边界：** 一维或单样本直接生成第一份普通 LHS，与同种子 classic 结果一致；两样本仍可正常返回分层设计。correlation 的 iterations 在搜索入口限定为正整数（支持 NumPy 整数，拒绝布尔、浮点、零/负数等），避免未生成任何候选时返回未定义变量。本项未改 maximin/center_maximin 的边界策略。
- **选优与坐标：** 在原有 unit 候选上计算相关性，保留真实值/编码值输出约定与局部 RNG。相关性按给定数量的候选选优，不保证全局最优或严格优于第一份普通 LHS；离散解码也不保证保持相关性。固定 100 点、3 维、seed=1、8 候选案例中，第一候选本身就是最优，两种方案最大绝对相关系数同为约 0.0146811，中英文 API 已说明具体语义。
- **验证：** 新增 [test_lhs_correlation.py](../tests/test_lhs_correlation.py)，修复前 **23 失败、1 通过**，修复后 **24 项通过**。9 组维度/样本数/种子组合用独立标准化点积计算全部候选得分，并逐元素确认返回最优候选；覆盖每列分层、完全正负相关、1/2 个样本、一维跳过相关计算、非法 iterations、静默输出、相同实例同种子复现、全局 RNG 不变、real/unit 对应和元数据。矩阵尺寸实测：100 点 3 变量，三次候选的相关矩阵均为 3×3，原先为 100×100。
- **范围与开销：** 生产修改限定在 `_lhs_correlate`。相关矩阵从 O(nSamples²) 改为 O(nInput²)，相关计算从 O(nSamples²×nInput) 改为 O(nSamples×nInput²)，样本多于维数时减少开销；不增加正常多维搜索的候选次数、模型评价或依赖。
