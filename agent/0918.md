## 2. 已确认的设计决定

| 主题 | 当前约定 | 接续开发注意事项 |
|---|---|---|
| 两类问题 | `Problem` 用于普通函数评价；`ModelProblem` 连接模型仿真与观测/指标评价 | 两者正式返回协议都是 `Eval`，用 `.objs`、`.cons`、`.sims` 访问 |
| `sims` 必要性 | `ModelProblem` 的 `target=None/sims` 按模拟契约返回；`target=objs/cons` 不强制在返回对象中带 `sims` | 内部仍可能需要仿真来计算目标；不要把“不返回 sims”误解为“不运行模型” |
| 按需评价 | 独立目标/约束回调按 `target` 执行 | 请求目标时不额外调用约束回调，反之亦然 |
| 核函数归属 | 类外核实例是构建模板，模型安装时复制 | 多模型不会通过同一核的可变参数相互污染；自定义核的外部资源可通过 `clone` 定义复制策略 |
| Matérn | 固定 `nu` 支持一般正值，并保留常用值/无穷极限专门路径；可调 `nu` 仍是规定候选集 | 一般正值的数值稳定性已修正，大 `nu` 的稳定积分路径较慢；不要宣传为任意规模下零成本 |
| 优化坐标 | 普通优化和代理辅助优化内部统一 `[0,1]`；真实模型评价经 Problem/Space 解码 | 代理辅助算法在单位空间训练/预测；独立使用代理模型仍可直接传自己的数据和 Scaler |
| 采样坐标 | DOE 默认输出真实值，算法可指定 `output='unit'` | 不应把真实采样结果再次当成编码值解码 |
| 推断坐标 | 推断保留连续潜在状态，评价与结果出口解码真实参数 | 推断所有连续轴没有统一改为 `[0,1]`；不能把优化约定机械套到贝叶斯算法 |
| 输出与持久化 | 优化结果出口恢复真实参数与原始目标方向；过程统计、种群快照、数据库保存有各自语义 | Reader 只能恢复实际保存过的快照，不能补出未保存的迭代 |
| 约束 | 可行解优先；不可行解按加权违反量比较；权重由 Problem 贯通种群、排序、结果与存储 | 多目标可行前沿和不可行候选分开；等违反量排名与历史最优比较使用一致规则 |
| MOASMO | 当前按无约束问题定位 | 用户明确暂不讨论约束代理/约束候选引导，不能把 M08 列为本轮遗漏的必修缺陷 |
| Scaler | 保留可选 Scaler，修正方差逆缩放、常数列等边界 | AutoTuner 先划分训练/验证，再拟合预处理，防止数据泄漏 |
| 校准指标 | 继续依据 metric label 决定方向 | `normalizedScore` 用于统一选优方向，不是把分数数值缩放到 `[0,1]` |
| PBIAS | 展示保留原始带符号值，选优按距零比较 | PBIAS 阈值为双侧范围；不擅自把原始指标公式变成绝对值 |
| 兼容策略 | 开发阶段暂不要求向后兼容 | 已移除旧 transform 包装和部分转发/别名，旧脚本需要同步正式接口 |

以下命令在新电脑的新目录执行；已有仓库先确认工作区干净，避免覆盖另一份本地修改。

```bash

cd UQPyL
git log -3 --oneline

conda create -n py312 python=3.12 pip
conda activate py312

```

源码含 Cython/C++ 原生扩展，新电脑需要适合本平台的编译工具链。pip 构建隔离会根据 pyproject.toml 安装构建依赖；不要复制旧电脑的 `.so`、虚拟环境或 Python 缓存。包名/版本仍显示 2.1.6 不代表安装错版本，请同时核对当前提交和 `UQPyL.__file__`。

检查 wheel 可复用 CI 的路径（需要联网安装构建和测试依赖）：

```bash
python -m pip install build
python -m build --wheel --outdir .cache/handoff-wheel
python .github/scripts/test_wheel.py --wheel-dir .cache/handoff-wheel --report-dir .cache/wheel-test
```

wheel 目录应只含当前平台本次构建的一个 wheel，避免混入旧产物。文档源在 `docs_v2/`，配置为 `mkdocs.yml`；可用 `python -m pip install -r docs-requirements.txt` 后执行 `python -m mkdocs build --strict`。

## 7. 对话关键决定摘录

以下为用户原话的选摘，附当前落地含义；省略中间来回，不构造未保存的完整对话。

> “那肯定是以本地端口为主，你先看一遍设计语言，我们再讨论”

以本地实现与确认过的设计作为工作基线，远程版本字符串不自动覆盖本地选择。

传入核作为构建模板，安装到模型时复制隔离。

> “我觉得可以，那就按0-1来，那你的方案是什么”

优化内部采用单位坐标；实际参数、独立采样、推断潜在状态仍分别遵循对应边界约定。

> “MOASMO 默认应该是不带约束的问题，这个暂时先不讨论”

> “我们目前还是按照metric的label，这里没有问题”

> “好的，直接修改为3.10吧”

最低 Python 版本改为 3.10，不再维持 3.8 声明。

> “你这个修复的问题很大，你多次检查一下和验证一下”

修复要求包含复现、对应回归和必要的全量验证；过程发现的问题修正后再测，不通过放宽数值断言交差。

已连续完成剩余 N 项与精简项，将默认优化器和预算政策留待最终讨论。
