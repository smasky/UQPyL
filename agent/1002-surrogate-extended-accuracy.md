## 主要结果

以下 R² 为 N=192 三个种子的中位数；范围另行指出。

| 场景 | 默认/基线 | 对照 | 判断 |
|---|---:|---:|---|
| `sin(12πx0)+0.1x1`，GPR | 0.713797 | 独立长度尺度约 1 | 共用长度尺度限制 |
| 八维但仅前两维有效，GPR | 0.704044 | 独立长度尺度约 1 | 无关维度影响距离与拟合 |
| 带 std=0.1 噪声正弦，GPR | 0.968331 | 放宽噪声范围 0.999721 | 默认噪声范围过小 |
| 输入单位相差 1e6，GPR | -0.045729 | 输入/输出缩放约 1 | 预处理与核尺度配置 |
| 纯三阶乘积，MARS | -0.644965 | 显式三阶 0.995158 | 二阶表达能力限制 |
| 局部尖峰，GPR | 0.652810 | 输出标准化 0.935978 | 改善但未充分解决 |
| 斜向不连续阶跃，GPR | 0.818539 | Matern 0.926950 / 放宽 C 0.902066 | 不光滑模型失配，仍有波动 |

### 1. 独立长度尺度有效，但不是自动提高所有维度模型复杂度的理由

`GpRbf(heterogeneous=True)` 在各向异性/八维稀疏例的三个种子都明显改善，N=64 也有效。默认 KRG 同样约 0.65～0.71；本轮没有对 KRG 做各向异性对照，不能把 GPR 改善数值直接套给 KRG。八维加性例 MARS R²=0.99906～0.99944，表现良好。应保留显式配置并验证，不据两个函数宣称全局默认 ARD 必优。

### 2. 默认 GPR 对噪声的参数范围确实不合适

真实训练噪声方差 0.01，默认 C 上限 1e-6，三个种子拟合均卡上界；长度同时卡下界 0.01。C 搜索改为 [1e-8,1] 后，估计为 0.00873～0.01086，接近真实值；长度约 0.30～0.34。测试 R² 由 0.89175～0.96977 提高至 0.99954～0.99975。潜在函数区间覆盖从 1.2%～2.1% 提高到本例 100%，这不是普遍校准证明。建议下一轮优先解决含噪声使用方式/范围设计；C 使用处理后目标方差单位，不宜不顾量纲直接设一个新通用上限。

### 3. 输入缩放不是装饰

物理单位例 GPR/KRG 未缩放 R² 接近零或负值，RBF 约 0.003～0.223；配置 MinMaxScaler 输入及 StandardScaler 输出后 GPR/KRG 接近 1，RBF=0.99987～0.99996，缩放后调参 SVR=0.99996～0.99999。该对照同时设置了输入和输出缩放，没有单独量化两者各自贡献。MARS 原始单位下也约 0.999。应在使用流程明确缩放选择，不把不同默认几何下的失效直接归为算法公式错误。

### 4. 默认二阶 MARS 的适用边界仍在

三阶纯乘积超出二阶表达范围，二阶三个种子 R² 都为负；显式三阶改善到 0.99365～0.99798。N=64 三阶有一个种子仅 0.76125，另外两个接近 1，说明样本与贪心拟合/剪枝也会影响表现。没有因此改回默认三阶；此处独立预测精度不能直接作为敏感性贡献精度结论。

### 5. 局部峰值、不连续、外推不能只看平均精度

- 峰函数 `exp(-sum(((x-.37)/.06)^2))` 的真实峰值为 1。输出标准化 GPR 的测试 R² 为 0.8695～0.9411，但中心预测仅 0.566～0.736。Matern 也会低估峰值。KRG 默认 R²=0.9114～0.9499；这些数据不足以保证峰值准确，需要峰附近覆盖/适应性补点另行验证。
- 阶跃函数 `1[x0+x1>1]`，默认 GPR 在一个种子上 R²=-0.59037；Matern 对照为 0.76547～0.94094，放宽 C 对照为 0.87710～0.90552。换核/允许平滑改善已观测案例，但不是彻底解决不连续函数；没有独立证据认定此处是新实现公式错误。
- 正弦短距离外推中，MARS R² 约 0.465，调参 SVR 为 0.163～0.980，RBF 约 0.902。GPR 在这个特定平滑函数上仍接近 1，不能推导为普遍外推可靠。KRG 均值 R²≈0.99998，但区间覆盖仅约 39%～41%，继续说明均值精度与不确定性校准是两件事。
