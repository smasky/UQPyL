# C15 默认零误差路径 · 2026-09-19

范围：用户同意先处理默认 R=0，同时说明观测通常不会过大。本轮只优化 `r=None`；不扩展对角误差接口，不改一般 R 的算法，不发布正式版。

## 实现与规模选择

- `r=None` 继续表示零观测误差，准备观测时不再创建大零矩阵。
- 有效观测数 **大于 ensemble 成员数**：直接对缩放后的集合异常矩阵做薄 SVD，计算增益，不形成 R 或 Cyy；诊断 `solver="svd"`。
- 观测数 **不超过 ensemble 成员数**：保留较小的原稠密求解。初始基准发现 32 成员/24 观测时 SVD 反而增加少量时间和工作空间，因此没有强制统一到 SVD。
- 显式 R（包括显式全零矩阵）保留既有校验和稠密路径。
- ES 与 IES 通过共用 `anomalyGain` 选择路径。模拟结果复用、mask、边界投影、参数接口和模型评价次数不变。

SVD 对 `dY / sqrt(nEnsemble-1)` 分解；保留 `nObs * eps * max(eigenvalue)` 的数值秩阈值，IES 的 lam 加在对应特征值上。正则化后，观测零空间中的方向可能贡献矩阵秩，但 Cxy 在该空间没有分量，不必构造零空间基。不同分解在截断临界点可能有浮点差异，不承诺逐位相同。

## 验证

- 小于/等于/大于成员数的观测维度；零误差与显式零矩阵对照。
- 零/正则化、零展开、观测零空间的秩，以及阈值两侧方向的手算验证。
- ES/IES 实际运行，mask、边界投影、三轮迭代结果及模拟调用次数。
- 阻断稠密协方差入口和 eigh，确认观测较多的默认路径只分解成员×观测矩阵。

## 保留事项

默认零误差的本轮范围已完成。一般稠密 R 自身及其观测协方差仍有平方级内存成本；对角/一般误差优化按用户当前规模需求暂缓，不再作为紧急缺陷。现有校准结果不因此被判定为错误。
