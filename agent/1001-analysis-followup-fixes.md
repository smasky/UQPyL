## 1. DeltaTest 组合搜索

`findCombEA` / `findCombVio` 不再直接平方原始输出，而是逐列中心化后用同一个幅值缩放，保持原多输出目标中的相对权重。不做逐列方差标准化。每列先独立进行二的幂次预缩放与中心化，再按非恒定列的共同幅值缩放；这样 `1e300` 常数列不会让另一列 `1e-200` 级变化提前消失。平方单位恢复也分离幅值尾数/指数，避免中间量下溢造成可表示的最终值归零。

EA 的 `bestObjs`、历史与数据库目标统一采用缩放后的输出平方单位；`extra["delta_selection"]` 和 OptReader 往返记录目标单位、汇总规则、尺度尾数/指数，以及物理目标下溢/溢出标记。物理平方不可表示时 warning，但缩放目标仍有效。空组合仍是无效组合，目标为 inf。新增 `seed` 支持可重复的实际 GA 搜索。

实测回归用两输入线性模型 `Y=3*x0+1`、128 行 LHS、seed=17。普通输出及 ×1e-200、×-1e-200、×1e200，穷举与真实 GA 均选择 x0；没有再误选无关变量或返回空组合。多输出相对权重和 SQLite 目标尺度记录通过。GA 不保证全局最优；极端不同的非恒定列幅值仍有双精度表示边界，未改变目标权重来掩盖这一限制。

## 2. Morris 单位区间模式（首轮实现，当前接口见上方）

默认 `effectMode="physical"` 保留原物理斜率 `ΔY/ΔX`。新增 `effectMode="unit"` 使用 `ΔY/(ΔX/input_range)`；改变输入单位并同步修改边界后，效应保持。效应本身仍有输出单位，只有输入步长无量纲。

连续/整数变量范围来自声明边界，数值离散变量来自实际值集 min/max；单位模式要求有限、严格正范围。没有新增无序类别解释。单位坐标 metadata 仍由正式入口解码，不重复解码，也不改变样本/输出。`extra["morris_effects"]` 记录模式、效应单位和使用的范围，SQLite 往返验证通过。

解析参照：`Y=3*x0-2*x1`，参数范围分别为 20 和 3，物理效应 `[3,-2]`，单位区间效应 `[60,-6]`、归一化 `[10/11,1/11]`。输入单位 ×0.001/×1000 加平移后，单位区间结果保持；两个二次函数轨迹独立验证效应 `[2,6]` 的均值 4 与样本标准差 √8，极小/极大输出缩放继续有效。

## 3. MARS 敏感性可靠性诊断

默认增加 GCV 搜索提示：若删变量的 GCV 改善同时大于训练输出方差的 2% 和完整模型 GCV 的一半，warning 并记录变量索引、改善比例及 `gcv_search_unstable`。这是启发式诊断，避免用几乎精确拟合中的微小误差触发告警；阈值可通过 `gcvImprovementTolerance` 配置。它不保证抓住所有偏差。

可选 `nValidationRepeats=3` 按局部种子 0、1、2 重复训练/留出，正式分数保留种子 0，不静默取平均。`extra["mars_stability"]` 保存每划分权重与 R²/GCV，各变量最小/最大/平均权重、标准差（ddof=0）及最大权重范围。范围超过 `stabilityTolerance=0.05`（5 个百分点）时 warning 并返回。默认一次划分标记未评估稳定性；多次划分的 stable 仅代表权重变化范围小。

保持默认 `maxDegree=2`、`minValidationR2=0.8`。默认不增加代理拟合次数，多次留出大致线性增加拟合耗时，复用已有输出，不额外评价原模型。实际线性模型多次划分与单次划分的正式结果逐值相同，原模型仍只评价一批。控制模型独立核对反转权重 `[0.8,0.2,0]` / `[0.2,0.8,0]` 的均值、标准差和范围，持久化诊断往返通过。

已复现旧反例：五输入 U[-1,1]、512 行 LHS seed=41，`Y=3*x0+2*x1*x2*x3`，显式三阶拟合的 R² 约 0.9656，却把 x0 权重推到 0.9912；理论删除变量损失归一化中 x0 为 0.8710。现在会提示删无关变量后 GCV 大幅改善的搜索异常。**告警使风险可见，但这个案例的原始敏感性偏差仍存在。稳定权重、高 R² 或没有 warning 都不构成准确性证明；贡献需对实际模型用独立参照、样本量/采样设计验证。**
