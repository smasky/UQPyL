## CAL01：SUFI2 内部采样没有保留整数/离散变量声明

**新确认的实际问题，建议优先修复。** CalibrationABC 的能力声明允许 integer/discrete；SUFI2._makeSamplingProblem 却仅传入 nInput/lb/ub，临时 Problem 被构造成全连续变量。后续直接 simFunc(X)，没有通过原问题的单位坐标解码补救。

公共 run 实验：一维整数域 [0,2]，以及声明离散选项 [.25,.75] 的问题；SUFI2(maxIters=2,nSamples=12)、eliteSize=4、seed=11。各例 24 次样本全部不满足原参数域，实际传入模拟器的值包括 1.01174、1.91857、0.69132，而非合法整数/选项。

同样问题改为外部传入合法 X，单轮执行保持合法值，两个对照通过。因此目前证据定位于**内部采样/后续范围迭代**，不是说所有 SUFI2 输入都错误。修复不能只拷贝 varType 后了事：离散值与编码区间不同，后续精英范围收缩也必须保持允许集合语义。

## CAL02：RMSE 极端量纲丢失排序，并影响真实校准选择

之前记录了极小尺度风险，本轮补充极大尺度与公共流程证据。原实现先平方再开根号，中间平方溢出/下溢，即使最终 RMSE 可表示也会错误。

观测 [1,2]，候选模拟 [[1.1,2.2],[1,2.1]]，正确 RMSE 分别为 .158113883 和 .070710678，第二个更优。共同乘尺度后：

| 尺度 | 实际结果 | 可表示的正确结果 |
|---|---|---|
| 1 | 正常 | .158113883 / .070710678 |
| 1e-200 | 0 / 0，无告警 | 1.58114e-201 / 7.07107e-202 |
| 1e200 | inf / inf，平方溢出警告 | 1.58114e199 / 7.07107e198 |

GLUE 阈值设为 .1×尺度，正确应只保留第二个候选。1e-200 时两个都被保留且 bestDecs 错选第一个；1e200 时错误报告没有行为样本。SUFI2(eliteSize=1) 在两个极端尺度都错选第一个。普通尺度两个流程均选对。

这是可修复的计算问题，不应仅加 warning 或填零。应稳定计算 RMSE 的范数/尺度，再覆盖公共排序行为。MSE 的真实平方量本身可能不可表示，不能把 RMSE 的可恢复范围直接当成 MSE 的保证。

## ES/IES：当前更新公式正确，后验含义需要区分

45 组独立矩阵控制：三个种子，24×2 集合，二维线性模型，R=0/相关 R 的两档大小，IES 1/3 步及 lam=0/.2；另核对 ES 单步。与独立协方差和 NumPy 伪逆逐步计算相比，最大参数差 **2.22e-15**。没有观察到这些正常配置下的增益或更新公式错误。

但当前代码是给每个成员使用同一观测的确定性更新，不是保持贝叶斯后验协方差的平方根或扰动观测更新。

一维恒等模型，用 [-1,0,1] 构造均值 0、样本方差 1 的集合，观测 1、R=1：

- 单步更新得到均值 .5、方差 .25。
- 若按同样先验矩假设高斯先验，线性高斯后验应为均值 .5、方差 .5。这个比较用于解释矩语义，不把三个离散成员说成真正高斯样本。
- IES 重复 3/10 次后，均值约 .65517/.79118，方差 .11891/.04361；反复贴近同一观测并收缩，不能把重复次数视为同一后验的采样收敛。

ES 文档已明确 deterministic update，故此处先归为**方法定位和结果解释风险**，不自动把当前公式改成另一种同化算法。若用户需要贝叶斯后验不确定性，需要单独明确目标和更新方案；仅把 posteriorDecs 的分位数当作正确可信区间是不充分的。
