# GPR 默认噪声搜索范围调整（2026-10-02）

用户确认修改后，将 GPR `C_attr` 的默认上限由 `1e-6` 调整为 `1.0`，下限仍为 `1e-12`、初值仍为 `C=1e-9`、按对数坐标搜索（同时将字符串 True 规范为布尔 True）。没有修改后验公式、默认缩放、独立长度尺度或优化器/重启次数。

C 是核矩阵对角线上的噪声方差/正则项，使用预处理后目标的方差单位；扩大搜索范围不是固定加入更大噪声。显式 `C_attr` 保持优先，`C_attr=None` 固定 C。默认上限 1 不是任意输出单位的通用界限，文档说明如何使用输出 Scaler 或自定义范围。

## 数值验证

[配对脚本](verification/check_gpr_noise_range.py)、[48 组记录](verification/1002-gpr-noise-range.json)、[结果摘要](verification/1002-gpr-noise-range.txt)。py312、单 BLAS/OMP 线程、`-W error`。LHS N=64/192，三个种子；噪声标准差 0/.03/.1/.3，旧范围与新默认配对，独立 4096 点与真实无噪声正弦函数比较。没有用测试点选择参数。

N=192 三个种子的结果：

| 噪声标准差 | 旧范围测试 R² | 新默认测试 R² |
|---|---|---|
| 0 | 接近 1 | 接近 1，三个种子与旧范围相同 |
| .03 | .99175～.99729 | .999961～.999980 |
| .1 | .90827～.96989 | .999542～.999747 |
| .3 | .17431～.72898 | .995988～.998471 |

新默认的估计噪声方差分别约 .00086～.00100、.00968～.01091、.08666～.09955，与真实 .0009/.01/.09 接近。无噪声仍选到下界约 1e-12。具体测试点与前轮不同，因此不直接混用不同报告的精度数字。此结果不保证任意函数、量纲或噪声机制的精度/区间校准。
