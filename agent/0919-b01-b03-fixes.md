# 2026-09-19 B01—B03 修复

范围：按用户要求修复再次复核中的 B01—B03，保留开发版本，不发布正式版。

- **B01：AutoTuner 失败状态。** gridTune/optTune 共用完整入口异常清理，覆盖预处理、参数应用、候选拟合、优化器调用、最终全量重拟合及中断。异常原样向上传递；清空 fitState 和训练数据引用，后续预测必须先重新拟合。与公共 fit 的既有规则一致，不提供参数/Scaler 回滚。原有候选数值错误记录和继续搜索规则不变。
- **B02：MultiSurrogate 重复实例。** 构造、append、fit、predict 检查模型类型和对象身份。拒绝重复模型，append 失败不改变容器；直接修改公开 models_list 后也会在使用子模型前拦截。保持独立传入实例的引用语义。
- **B03：MARS 导数量纲。** predict_deriv 使用与 predict 相同的输入处理，并按输出 inverseScale / 输入 inverseScale 还原导数。支持内置 StandardScaler/MinMaxScaler、未缩放以及不同输出尺度。PolyFeature 和不提供仿射契约的 Scaler 明确报 NotImplementedError。变量索引在进入 Cython 前检查范围，支持变量名与 NumPy 整数。
- **B03 联动底层缺陷。** 多变量回归发现 transform_deriv 跳过无关基函数时没有推进系数索引，因此套用了其他基函数的系数。现在仅剪枝基函数不占系数位置，未剪枝但导数为零的基函数仍推进索引。该问题在无 Scaler 时也存在，已一并修正。
- **B04 部分覆盖。** predict_deriv 增加 requireFitted，旧导数在 fit 失败后被拒绝；transform 等剩余派生入口仍待 B04 统一处理，不能标记整个 B04 完成。B05/B06 本轮未处理。
