# 替代模型精度改进（2026-10-02）

承接 [精度审查](1002-surrogate-accuracy.md)，本轮实际修改默认配置，并用预测误差验证；未用 warning 替代修复。

## 修改

1. GPR RBF、Matern、RationalQuadratic 的默认长度尺度下界统一由 1 改为 0.01，上界 1e5、初值 1、优化器/重启次数不变。三个核原来有相同限制，分别增加独立预测回归。自定义范围和固定参数协议保持；长度使用预处理后的输入单位，不自动改变用户数据尺度。
2. 独立替代模型 MARS 默认 `max_degree=2`，与敏感性分析默认二阶一致；仍可显式选一阶。没有改 MARS 基函数、剪枝公式或敏感性统计量。增加交互可能增加拟合成本，不保证高维/高阶精度。
3. SVR 保持显式 fit 参数语义，不暗中调参。现有 AutoTuner 验证集调参路径实测可解决本轮欠拟合案例，补充文档和数值回归。候选集 C=[1,100]、epsilon=[.001,.01]、gamma=[1,10,100]，按 log 编码传 gridTune，25% 内部留出、选定后全量重拟合，独立 4096 点不参与选择。该网格不是通用最优配置。
4. GPR 标准差公式没有改，没有人为扩大区间。本轮搜索范围修正消除了已复现的失配和极端过度自信；文档明确标准差不是实际误差保证，任意任务的不确定性校准仍不能宣称解决。
