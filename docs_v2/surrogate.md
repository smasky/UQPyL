# Surrogate Modeling

The `surrogate` module trains predictive models for expensive simulations or objectives.

## Public Components

| Component | Examples |
|---|---|
| Radial basis models | `RBF` |
| Gaussian process models | `GPR` |
| Kriging models | `KRG` |
| Regression models | `LinearRegression`, `PolynomialRegression` |
| Utilities | `Scaler`, `MinMaxScaler`, `StandardScaler`, `KFold`, `RandSelect`, metrics |
| Tuning | `AutoTuner` |
