# Changelog

本页记录 UQPyL 及其文档中面向用户的变更。

## 2.1.7（待发布）

### 计算与运行修复

- 修复敏感性分析中的单位缩放、极端数值范围和 DeltaTest 并列邻居处理；完善 MARS 留出验证告警。
- 修复优化算法的部分选择、最优结果保留及指标数值范围问题。
- 修复推断算法的部分转移、适应期和概率检查问题，并补充已知分布验证。
- 改进校准后验更新、评分数值稳定性及低有效样本量诊断；统一校准结果字段。
- 改进替代模型默认配置、求解稳定性与不确定性处理，补充独立测试集精度验证。
- 修复 DoE 边界处理、Problem 范围转换和单点评价缓冲区复用问题。
- 修复 SQLite 创建时间一致性、敏感性绘图原值、优化曲线坐标对齐和参考点显示。

- 统一二维模拟矩阵的 masked NaN 处理，修复掩码文档示例的降维错误，并明确替代模型预测维度提示。

### 接口与环境

- `ModelProblem` 正式统一为一维 `obs/mask` `(nObs,)`、二维 `simFunc` 输出 `(nSamples,nObs)`；原始网格由用户按相同观测顺序显式展平，拒绝旧布局。
- 移除观测标签 `obsLabels`；CalResult/SQLite 汇总使用观测数 `nObs` / `n_obs`（`n_output=n_obs`），移除 `nTime/nSeries/seriesLabels/obsShape`；旧校准数据库需重新运行生成。

- 最低 Python 版本为 3.10，版本声明和构建矩阵扩展至 Python 3.14。
- 替代模型采用单输出协议，多输出通过 `MultiSurrogate` 组合。
- Morris 按参数范围报告 elementary effects；MARS 默认二阶交互。
- `plot_sa` 直接绘制保存的指标，不再自动归一化；通过 `metric` 和 `outputIndex` 选择指标与输出。
- 本版本包含接口及默认行为调整，升级时请核对对应模块指南。

### 验证状态

- 当前源码在 conda py312 中通过 3175 项测试（-W error），包括观测向量协议、排列顺序、SQLite 往返和文档执行；四种校准方法迁移前后的数值数组完全一致。
- 此条目为发布准备记录，不表示 2.1.7 已上传 PyPI；最终安装包和跨平台 CI 验收仍待完成。

### 文档

- 将文档重构为面向用户的工作流指南。
- 将 API 参考拆分为 `problem`、`doe`、`analysis`、`optimization`、`inference`、`calibration`、`surrogate` 等模块页面。
- 扩展示例，加入可运行代码、期望输出、verbose 输出片段和常见错误。
- 增加对 `Problem` 评估、批量目标函数、标量/向量边界、结果对象和 sqlite reader 的说明。
- 增加中文用户文档，包括 Quick Start、模块指南、Examples、API Reference 和拆分 API 摘要页。

### 注意

- `Problem.evaluate()` 的正式返回协议是 `Eval` 对象。使用 `res.objs` 和 `res.cons`，不要使用字典式访问。
