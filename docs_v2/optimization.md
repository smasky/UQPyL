# Optimization

The `optimization` module searches for optimal decisions in a `Problem`.

## Algorithm Groups

| Group | Algorithms |
|---|---|
| Single-objective | `GA`, `PSO`, `DE`, `SCE_UA`, `ML_SCE_UA`, `CSA`, `ABC` |
| Multi-objective | `NSGAII`, `NSGAIII`, `MOEAD`, `RVEA` |
| Expensive optimization | `ASMO`, `EGO`, `MOASMO` |
